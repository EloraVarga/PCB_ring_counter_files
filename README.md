⚡ 8-Bit Ring Counter PCB Design & Prototyping
A complete end-to-end hardware engineering project featuring schematic capture, printed circuit board (PCB) design, manufacturing, and manual assembly of an 8-bit Ring Counter circuit.

📌 Project Overview
This project demonstrates the full lifecycle of a digital hardware prototype. Designed using PADS Logic / PADS Layout, the board features a shift register-based ring counter driving an LED display array to visualize sequential bit shifting in real time.

🛠️ Tech Stack & Hardware Components
EDA Tool: PADS Logic (Schematic Capture & Layout)
Digital ICs: 74HCT194 / Shift Registers & Logic Gates
Manufacturing: Ordering fabricated PCB boards from China
Assembly: Manual SMD & Through-Hole Component Soldering and Testing

🚀 Key Features
Full Design Cycle: Transitioned from theoretical logic design to a physical, working circuit board.
Component Assembly: Hands-on soldering and visual verification of signals across the board.
Modular Logic: Clock-driven sequential circuit with clear state visualization via LEDs.
